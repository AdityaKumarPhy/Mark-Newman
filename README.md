## Setup

Clone repository:

```bash
git clone https://github.com/AdityaKumarPhy/Mark-Newman.git
```

Create virtual environment:

```bash
python -m venv .venv
```

Activate environment:

### Linux/macOS

```bash
source .venv/bin/activate
```

### Windows

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```
